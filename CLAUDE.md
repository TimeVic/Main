## Project Overview

**TimeVic** is an ASP.NET Core time-tracking platform built on .NET (SDK pinned via `global.json` with `rollForward: latestMajor`).

## Request/Handler Pattern

All API endpoints use a custom `IAsyncRequestHandler<TRequest, TResponse>` — **not MediatR**.

```
Controllers/Dashboard/TimeEntry/
  TimeEntryController.cs         ← thin, just routes
  Actions/
    StartRequestHandler.cs       ← all logic lives here
```

Controllers extend `MainApiControllerBase(ILifetimeScope scope)` and dispatch via:
```csharp
// With response:
=> this.RequestAsync().For<TimeEntryDto>().With(request);

// Without response:
=> this.RequestAsync(request);
```

Handlers implement `IAsyncRequestHandler<TRequest, TResponse>` and are auto-registered by Autofac in `ApiModule.cs` via `AsClosedTypesOf`.

## Dependency Injection (Autofac)

- Use **Autofac modules** — not `IServiceCollection`.
- `IDomainService` → `InstancePerDependency`; `IScopedDomainService` → `InstancePerLifetimeScope`.
- DAOs implement `IDomainService` and are resolved from scope automatically.
- Key modules in `TimeTracker.Business/Di/Autofac/Modules/`: `DbModule`, `DomainModule`, `QueueModule`, `NotificationsModule`, `ExternalClientsModule`.

## ORM & Database

- **NHibernate + FluentNHibernate** against **PostgreSQL** (port `5433` by default).
- All entities extend `AEntity` (`Id: Guid`, `CreatedAt`, `UpdatedAt`, `DeletedAt`, `IsDeleted`, `IsNew`).
- IDs are **UUID v7** (`GuidV7Generator`) — always generated by the app, never the DB.
- Mappings: `TimeTracker.Business.Orm/Mapping/Entities/`, extend `BaseGuidMappings<T>`.
- **`SnakeCaseConvention`** converts `PascalCase` → `snake_case` automatically; explicit overrides go in the mapping class.
- **Transactions**: `CommitPerformerMiddleware` wraps each request. Do **not** manually commit in handlers.
- Run migrations: `dotnet run --project ./TimeTracker.Migrations`

## Queue System

Three channels: `Default`, `Notifications`, `ExternalClient`.

To enqueue work:
1. Create a context class implementing `IQueueItemContext` (or `INotificationItemContext` / `IExternalServiceItemContext`).
2. Create a handler implementing `IAsyncQueueHandler<TContext>` (auto-registered via `QueueModule`).
3. Push via `IQueueService.PushDefaultAsync(ctx)` / `PushNotificationAsync(ctx)` / `PushExternalClientAsync(ctx)`.

## Exception Handling

- Domain exceptions implement `IDomainException` → caught by `ExceptionHandlerActionFilter` → HTTP 400.
- Use helpers: `RecordNotFoundException.ThrowIfNull(entity)` or `throw new HasNoAccessException()`.
- Source: `TimeTracker.Business.Common/Exceptions/`.

## Testing

| Project | Type | Base class |
|---|---|---|
| `TimeTracker.Tests.Integration.Api` | API integration (HTTP) | `BaseTest : IClassFixture<ApiCustomWebApplicationFactory>` |
| `TimeTracker.Tests.Integration.Business` | Business/DAO integration | `BaseTest` (Autofac container) |
| `TimeTracker.Tests.Unit.Business` | Unit | `BaseUnitTest` |

Key patterns:
- DB wiped before each test via `IDbCleanUpService.CleanUp()`.
- `IUserSeeder.CreateAuthorizedAsync()` → `(jwtToken, user, defaultWorkspace)`.
- `IDataFactory<TEntity>` for Faker-generated stubs (`.Generate()`).
- Call `FlushDbChanges()` before re-querying; use `FlushAndRefreshEntity(entity)` to reload NHibernate objects.
- Mocked externals: `SmtpClientServiceMock`, `FirebaseClientServiceMock`, `ClickUpClientMock`, `RedmineClientMock`, `JiraClientMock`.
- Queue in tests: `await QueueProcess(QueueChannel.Default)`.

```bash
dotnet test ./TimeTracker.Tests.Integration.Api
dotnet test ./TimeTracker.Tests.Integration.Business
dotnet test ./TimeTracker.Tests.Unit.Business
```

**Prerequisites:** PostgreSQL on port `5433` with credentials from `appsettings.Testing.json`.
